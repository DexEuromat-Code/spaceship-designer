1Overview

Spaceship Designer is a 2D planning tool for Space Engineers ships. You design the ship slice by slice (layers) from bow to stern and check the result in a top view.

Coordinates used throughout the app:

  • Layer — one 33 × 33 cross-section of the ship. Layer 1 is the bow, the last layer is the stern.
  • Level — the height inside a layer. Level 33 is the top row of the grid, level 1 the bottom row.
  • X — the column (1–33). Column 17 is the ship's center line.

The screen is split into these areas:

Title barProject name, Help, Save to JSON, Load JSON, New project
Left columnCreate block · Block palette · Tool · Options · Ship length
CenterLayer editor — the 33 × 33 cross-section of the current layer
Right columnTop view — one level seen from above, Print to PDF

2Quick start

  1. Type a name for the project in the field in the title bar.
  2. Pick the ship length (25–125 layers) and the build direction — from the bow or from the stern.
  3. Create a few blocks in Create block — or load a ready palette with Load palette.
  4. In the layer editor click Edit, select a block in the palette and paint on the grid.
  5. Click Save to store the layer, then move to the next layer with ▶.
  6. Check the shape in the Top view and save the project with Save to JSON.

3Design limitations

Please keep in mind that:

  1. Designs make no distinction between large grid and small grid.
  2. Blocks are always full-size — there is no distinction for half blocks or sloped (angled) blocks.
  3. When designing moving blocks such as pistons, it is recommended to use one of the two extreme positions: 2 blocks (retracted) or 6 blocks (extended).
  4. A block cannot be designed at an arbitrary angle (only in the vertical or horizontal plane). If angles are necessary, add suitable notes to the layer that contains the rotor or hinge.
Notes are entered in the Layer notes field under the layer grid — see Layer editor.

4Creating blocks

A block is a named color you paint with — e.g. “Heavy Armor”, “Glass”, “Thruster”.

New block

  1. Enter the Block name — up to 25 characters (the counter under the field shows how many are used).
  2. Click the color square to choose the Block color. The preview next to it shows the color, the name and the HEX code.
  3. Click Save. The block is placed in the palette:
    • into the selected slot if it is empty,
    • otherwise into the first free slot on the current page, then anywhere in the library,
    • if all slots are taken — into the library, on a new page (see Block palette).

Editing a block

  1. Select the block in the palette.
  2. Click Edit — the name and color are loaded into the form and the slot is marked with ✎.
  3. Change what you need and click Save. All layers using that block are updated immediately.
  4. To abandon the change, click Cancel edit.

5Block palette & library

The palette shows 10 slots at a time, numbered 01–10. Click a slot to select it as the active block (highlighted with an orange frame). Hover over a slot to see its full name, color and shortcut key.

Library pages

When all visible slots are taken, new blocks are saved to the library on further pages. Once there is more than one page, page controls appear under the palette:

  • ⏮ first page, ◀ previous page, ▶ next page, ⏭ last page.
  • Numbering continues across pages: page 2 holds slots 11–20, page 3 21–30, and so on.
  • The counter under the palette shows how many blocks are in the library (max. 990).

Saving and loading a palette

  • Save palette — saves the whole library (all pages) to <project>_palette.json.
  • Load palette — replaces the current palette with one from a file. Both palette files and full project files are accepted, so you can reuse the palette of another ship.
Painted cells remember the slot number, not the block itself. If your layers already contain blocks and the new palette has something different in those slots, the app lists the affected slots and asks for confirmation. Best practice: load the palette before you start painting.

An example palette with six basic colors is included in examples/basic-colors_palette.json.

6Tools & options

ControlWhat it does
Brush (B)Paints the selected palette block.
Eraser (E)Clears cells. You can also erase with the right mouse button while the brush is active.
Left–right symmetryEvery cell you paint or erase is mirrored on the other side of the center line. An orange dashed line through the middle of the grid confirms the option is on. Cells in the center column (17) lie on the axis and are not duplicated.
Show previous layerShows the previous layer (according to the build direction) as a faint, semi-transparent shadow under the current one — helpful for keeping the hull smooth.
Bow → Stern / Stern → BowBuild direction — decides which layer counts as “previous”:
  • Bow → Stern (default): previous = the layer on the bow side (N−1).
  • Stern → Bow: previous = the layer on the stern side (N+1).
It affects Copy previous and Show previous layer. The direction is saved in the project file, and a loaded project opens at the layer where the build starts (layer 1 or the last layer). Layer numbering does not change — layer 1 is always the bow.

7Ship length

Choose the number of layers: 25 50 75 100 125. Lengthening the ship adds empty layers at the stern.

Shortening the ship deletes the layers beyond the new length. If any of them contain blocks, the app asks for confirmation first.

8Layer editor

The central 33 × 33 grid is a cross-section of the ship, viewed from the bow toward the stern. The slightly brighter lines mark the center column and center row. The orange dashed frame marks the level currently shown in the top view. Under the grid you can see the X coordinate and level of the cell under the cursor.

Navigation

  • ⏮ first layer (bow), ◀ previous, ▶ next, ⏭ last layer (stern).
  • Type a number in the Layer field to jump directly.
  • Clicking a row in the top view opens that layer as well.

Buttons

ButtonWhat it does
EditUnlocks the layer for painting. Without it the layer is read-only, which protects it from accidental changes.
SaveStores the layer in the project and locks it again.
Copy previous (N)(while editing) Loads the content of the previous layer into the editor — a quick way to extend a constant hull section. Which layer is “previous” depends on the build direction; its number is shown on the button.
Copy from layer…(while editing) Opens a dialog for copying any saved layer — e.g. to repeat an engine section.
  • While the dialog is open, layer numbers appear next to the top view: saved layers are bright, empty ones dim, the edited layer is orange.
  • Type the source layer number or click its row in the top view. The chosen layer is highlighted in green and the dialog shows how many blocks it has.
  • Click Copy (or press Enter); Cancel or Esc closes the dialog.
DeleteClears the whole layer, including its notes (after confirmation).

Layer notes

The Layer notes field under the grid holds a free-text remark for the current layer (up to 256 characters, the counter shows how many are used), e.g. the swing range of a rotor or hinge — see Design limitations.

  • The field is read-only until you click Edit; changing the text marks the layer as “unsaved”.
  • Save stores the notes together with the layer, also in the project JSON file. A layer may hold notes even without blocks.
  • Delete removes the notes as well. Copy previous and Copy from layer… copy only the blocks, not the notes.

Layer status

  • Empty — nothing saved in this layer.
  • Saved — the layer contains saved blocks.
  • Editing / Editing • unsaved — edit mode is on; “unsaved” means there are changes not yet saved.
If you leave a layer with unsaved changes, the app asks whether to discard them.

9Top view

The top view shows one level of the whole ship from above: 33 columns wide, one row per layer, bow at the top and stern at the bottom. By default the highest level (33) is shown.

  • ⤒ highest level, ▲ one level up, ▼ one level down, ⤓ lowest level (1).
  • The current layer of the editor is framed in orange.
  • Dark-blue cells show the silhouette — blocks that exist in that column on other levels — to help you keep orientation.
  • Click any row to open that layer in the editor.

10Print to PDF

The Print to PDF button under the top view prints the top view of every level — from the lowest level (1) to the highest (33), one level per A4 page.

  1. Optionally untick Skip empty levels (ticked by default) if you want all 33 pages.
  2. Click Print to PDF.
  3. In the browser's print dialog choose Save as PDF (or Microsoft Print to PDF) as the printer and save the file.

Each page contains the ship name, the level number, column numbers (1–33) and layer numbers, plus a legend of blocks used on that level. Light-gray cells are blocks on other levels.

Only saved layers are printed — save the layer you are editing first. For long ships (125 layers) the grid is scaled to fit the page height, so the cells are small.

11Saving & loading

ButtonWhat it does
Save to JSONDownloads the whole project (name, length, palette, all saved layers) as <project>.json.
Load JSONOpens a project file and replaces the current project.
New projectClears everything and starts from scratch (after confirmation).
Save palette / Load palettePalette only — see Block palette.
The current project is also saved automatically in your browser after every change and restored the next time you open the app. This is a convenience only — keep important ships as JSON files.

Project file format

{
  "app": "se-ship-designer",
  "version": 2,
  "name": "My ship",
  "length": 25,
  "direction": "bow",          // or "stern"
  "palette": [ { "name": "Heavy Armor", "color": "#7a8a9c" }, null, … ],
  "layers": [
    { "layer": 1, "notes": "Rotor: ±45°", "rows": [ [-1,-1,0,0,…], … ] }   // 33 rows × 33 cells; "notes" optional
  ]
}

Each cell holds the palette slot index (0 = slot 01) or -1 for an empty cell. Row 0 is the top level (33).

13Tips & FAQ

I can't paint on the grid.

Click Edit first. Also make sure the selected palette slot contains a block (not “empty”).

My changes disappeared after switching layers.

Layers have to be saved with Save before you leave them. The app warns you about unsaved changes.

How do I build a long hull section quickly?

Save one layer, go to the next, click Edit → Copy previous → Save, and repeat. If you build from the stern, switch the build direction to Stern → Bow first and move with ◀.

How do I repeat a section from elsewhere in the ship?

Open the target layer, click Edit → Copy from layer…, pick the source layer in the top view and click Copy.

How do I keep the ship symmetrical?

Turn on Left–right symmetry and paint only one half — the other side is mirrored automatically.

Where does the app keep my work?

In your browser (automatically) and in JSON files you save. Clearing the browser data removes the automatic copy, so save JSON files regularly.
